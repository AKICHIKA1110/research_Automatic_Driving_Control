# 深層学習による画像認識を用いた白線追従の自動運転制御

[← README に戻る](../../README.md)

カメラ画像から深層学習モデルで白線を認識し、車両を自動走行させる。

## 構成（予定）

カメラ(RGB) → 白線検出(CNN) → 鳥瞰変換したマスク → 曲率 CNN → 中心線 7 点＋信頼度 → フィット層 → e_y・e_ψ・κ(s) → MPC → `/controller/cmd_vel`
